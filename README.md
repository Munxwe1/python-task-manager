# Python Task Manager

Консольный менеджер задач на языке Python. Учебный проект для лабораторных работ
№3 и №4 по работе с ветками Git, слиянием, Pull Request и оформлением репозитория.

## Описание

Программа хранит список задач и позволяет добавлять их, отмечать выполненными,
удалять, искать по названию и смотреть статистику выполнения. Проект решает
простую задачу — вести учёт дел из консоли без установки сторонних программ —
и служит учебным примером для освоения Git и GitHub.

## Возможности

| Функция | Описание |
|---------|----------|
| `add_task(title)` | Добавление задачи с проверкой названия |
| `list_tasks()` | Просмотр списка всех задач |
| `complete_task(task_id)` | Отметка задачи как выполненной |
| `delete_task(task_id)` | Удаление задачи по номеру |
| `search_tasks(text)` | Поиск задач по части названия без учёта регистра |
| `filter_tasks(done)` | Отбор выполненных или невыполненных задач |
| `get_stats()` | Статистика: всего, выполнено, осталось, процент выполнения |

## Технологии

- Python 3.10 и новее (программа использует только стандартную библиотеку);
- pytest — модульные тесты;
- Git и GitHub — контроль версий, ветки, Pull Request.

## Требования

1. Python 3.10 или новее.
2. pip для установки зависимостей.
3. Git для клонирования репозитория.

## Установка

1. Клонируйте репозиторий и перейдите в папку проекта:

```bash
git clone https://github.com/Munxwe1/python-task-manager.git
cd python-task-manager
```

2. Создайте и активируйте виртуальное окружение:

```bash
python -m venv venv
venv\Scripts\activate        # Windows
source venv/bin/activate     # Linux / macOS
```

3. Установите зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python src/main.py
```

Запуск тестов:

```bash
python -m pytest
```

## Использование

Пример работы с функциями программы в интерактивном режиме Python:

```python
>>> import sys; sys.path.insert(0, "src")
>>> import main
>>> main.add_task("Сдать лабораторную работу")
{'id': 1, 'title': 'Сдать лабораторную работу', 'done': False}
>>> main.complete_task(1)
True
>>> main.get_stats()
{'total': 1, 'done': 1, 'left': 0, 'percent': 100}
```

Пример вывода `python src/main.py`:

