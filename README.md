# python-task-manager

Консольный менеджер задач на Python. Учебный проект для лабораторной работы №3
по работе с ветками Git.

## Возможности

- добавление задачи;
- просмотр списка задач;
- отметка задачи как выполненной.

## Запуск

```
python src/main.py
```

## Тесты

```
pip install -r requirements.txt
python -m pytest
```
